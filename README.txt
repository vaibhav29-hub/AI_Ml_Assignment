ML Lab Assignments - Code

1. Install libraries:
   pip install -r requirements.txt

2. Run any assignment from inside this folder:
   python a1.py   (and so on up to a10.py)

3. a9.py and a10.py use vtest.avi (included in this folder), so keep it in the same folder.

Graphs are saved as .png files in the same folder.
a9.py also saves output_detected.avi, and a10.py creates multimodal_news.csv and a news_images folder.
